# rtl-press

Turn a folder of Markdown files into a fast, SEO-ready Arabic (right-to-left) website or blog.

> Status: early development.

## Planned features

- [ ] Markdown to HTML with correct RTL layout and Arabic fonts
- [ ] Mixed Arabic/English text handled properly
- [ ] Templates and themes (light and dark)
- [ ] SEO: meta tags, Open Graph, sitemap.xml, robots.txt, structured data (schema.org)
- [ ] Tags, categories and pagination
- [ ] Image optimization
- [ ] Client-side search that works with Arabic
- [ ] Local preview server with live reload
- [ ] Command-line tool
- [ ] Automated tests

## Planned usage

```bash
rtl-press new my-site
rtl-press build
rtl-press serve
```
